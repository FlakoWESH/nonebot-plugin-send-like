# nonebot-plugin-send-like

NoneBot2 点赞与自动回赞插件，支持手动点赞和资料卡赞满自动回赞。基于 Alconna 命令解析器优化，JSON 文件持久化，零数据库依赖。

## 功能特性

- **手动点赞**：发送命令给指定用户点赞，支持一次@多名用户
- **自动回赞**：当有人给 Bot 资料卡点满赞（达到阈值）时，自动回赞
- **可配置回赞次数**：Bot 回赞数量可配置（默认50次，Bot可给非好友点50赞）
- **点赞阈值可配**：触发自动回赞的点赞次数阈值可配置（默认10次，普通用户每日上限）
- **幂等性保证**：当日已回赞的用户不会重复回赞
- **自动清理**：启动时自动清理30天前的过期点赞记录
- **JSON 持久化**：零数据库依赖，异步文件锁保证并发安全

## 安装

### 使用 nb-cli（推荐）

```bash
nb plugin install nonebot-plugin-send-like
```

### 使用 pip

```bash
pip install nonebot-plugin-send-like
```

然后在 `pyproject.toml` 中添加：

```toml
[tool.nonebot]
plugins = ["nonebot_plugin_send_like"]
```

## 使用方法

### 手动点赞

```
点赞 @用户1 @用户2
```

别名：`赞`

示例：
```
点赞 @123456
点赞 @用户1 @用户2 @用户3
```

### 自动回赞

无需手动触发，当有人给 Bot 资料卡点满赞时自动回赞。

**触发条件**：
1. 事件类型为好友资料卡点赞（`notice.notify.friend_praise`）
2. 用户当日累计点赞数达到阈值（默认10次）
3. 当日尚未回赞过该用户

**回赞行为**：
- Bot 自动给对方点赞，默认50次（Bot可给非好友点50赞）
- 回赞后标记该用户当日已回赞，不会重复触发

## 配置项

在 `.env` 文件中添加以下配置（均为可选，有默认值）：

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `SEND_LIKE_AUTO_RETURN` | bool | true | 是否启用自动回赞功能 |
| `SEND_LIKE_PRAISE_THRESHOLD` | int | 10 | 触发自动回赞的点赞次数阈值（普通用户每日上限10次，会员20次） |
| `SEND_LIKE_RETURN_TIMES` | int | 50 | Bot 自动回赞的次数（Bot可给非好友点50赞） |
| `SEND_LIKE_MANUAL_TIMES` | int | 10 | 手动点赞命令每次点赞的次数 |
| `SEND_LIKE_DATA_FILE` | str | "data/send_like_records.json" | 点赞记录JSON文件路径 |

## 点赞次数说明

| 用户类型 | 每日可给单个用户点赞上限 |
|----------|--------------------------|
| 普通QQ用户 | 10次 |
| QQ会员 | 20次 |
| Bot（机器人账号） | 50次（可给非好友点赞） |

因此，默认配置下：
- 普通用户给 Bot 点满10赞 → 触发自动回赞
- Bot 回赞50次 → 点满对方资料卡

## 注意事项

1. **协议端支持**：自动回赞依赖协议端上报 `friend_praise` 通知事件，部分协议端可能不支持
2. **好友关系**：Bot 给非好友点赞上限为50次，给好友点赞可能受QQ限制
3. **数据存储**：点赞记录按日期分组存储，启动时自动清理30天前数据
4. **并发安全**：使用异步文件锁，多协程并发写入不会损坏数据
